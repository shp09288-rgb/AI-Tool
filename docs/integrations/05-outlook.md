# Outlook

## Role

For **Technical Support** Work Orders (출장/현장 대응 등), automatically **compose** the email the engineer would otherwise write by hand, including Work Order context as attachment or Salesforce link. User sends after review.

## Flow

```text
Case (field / 출장 대응)
  → Work Order Record Type: Technical Support
  → User opt-in on Case
  → AI draft To / Cc / Subject / Body
  → Graph: create Outlook Draft (+ attachment)
  → User opens Outlook → edit → Send
  → Optional: Activities note (draft created / Message-ID)
```

## API availability

| Capability | Available | Notes |
|------------|-----------|-------|
| Create draft | Yes | `POST /me/messages` or `/users/{id}/messages` |
| sendMail | Yes | **Do not use for v1 default** |
| Attach file &lt; 3MB | Yes | `fileAttachment` on draft |
| Large attachment | Yes | upload session (≤ ~150MB) |
| Auth | Entra OAuth | `Mail.ReadWrite` (+ `Mail.Send` only if later enabled) |

Docs: [Create and send messages](https://learn.microsoft.com/en-us/graph/outlook-create-send-messages)

## Auth

- Delegated (user signs in — drafts appear in **their** mailbox) — best UX for personal outbound mail.
- Or application + mailbox access policies (harder; needs Exchange admin).

**Recommendation:** delegated Graph for the operating engineer’s mailbox.

## How we connect

```text
1. Collect recipients (Contact/Account from Case, or user-editable).
2. Body template: site, tool, symptom, WO number, SF deep link.
3. Attachment options:
   a) PDF/HTML summary generated by Tool
   b) Link only to Salesforce WO (simplest, no file)
   c) Export from SF if org provides (future)
4. POST draft → return webLink / draft id in Tool UI.
5. Never call send unless user enables “auto-send” later.
```

### Suggested draft contents

- Subject: `[Technical Support] {Site} / {Tool} / {short symptom}`
- Body: Case Subject, WO number, Relevant facts, requested actions, SF URL
- Attachment filename: `WO-{number}-summary.pdf` (optional)

## Usage scenarios

1. Selected Case with Technical Support WO → one-click “Create mail draft”.
2. Batch: multiple selected Cases → multiple drafts (rate-limit aware).
3. Failure: show local draft text for copy-paste if Graph denied.

## Risks

- Auto-send to customers is high risk — keep draft-only.
- Wrong recipient from Account/Contact mapping — Human Gate on To/Cc.
- Shared mailbox permissions differ from `/me`.
